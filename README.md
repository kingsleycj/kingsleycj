## About Me

I'm a software developer who enjoys turning messy requirements into clean, reliable APIs. Most of my day-to-day is spent in **Node.js, TypeScript, and MongoDB**, building and hardening production systems for platforms that can't afford downtime. Alongside that, I'm actively growing into **blockchain development** — Solidity, Hardhat, and Web3 tooling.

```yaml
  learning: [Solidity, Smart Contracts, Web3 Integrations]
  fun_fact: "I debug in production... just kidding (mostly)."
```

- 🔭 **Currently building** backend infrastructure for **HarmonyKloud**, an ABA therapy platform (Node.js/TypeScript/MongoDB) — recent work spans audit-log systems, push notifications, and bug triage.
- 🎨 **Also contributing to VibeCraft**, an AI-powered creative suite — API documentation and technical architecture decisions.
- ⛓️ **Learning in public**: smart contract development, blockchain security, and Web3 integrations.
- 🌱 **Sharpening fundamentals**: API design, database architecture, and system reliability.
- 💬 **Ask me about**: Node.js backend architecture, MongoDB data modeling, or getting started in Web3.
